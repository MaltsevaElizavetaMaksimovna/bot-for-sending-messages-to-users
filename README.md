# VK_bot - back-end

Backend-часть командного проекта для **отложенных рассылок сообщений** в VK Teams.

 **Проект находится в активной разработке.**  
Данный ветка представляет только back-end часть и **не является финальной версией продукта**.

---

## О проекте

Проект разрабатывается командой и в будущем будет включать:

-  **Полноценный web-сайт** (отдельный frontend)
-  **Авторизацию и роли пользователей**
-  Расширенную аналитику рассылок
-  Масштабируемую архитектуру

> Текущий web-интерфейс в этом репозитории — **временный технический UI**,  
> используется **исключительно для отладки и демонстрации backend-логики**  
> и **будет заменён** полноценным frontend-приложением.

## Запуск (для разработки)

### 1 Установка зависимостей
```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
### 2️ Конфигурация
```
cp .env.example .env
```
Пример .env:
```
BOT_TOKEN=your_vk_teams_bot_token
DB_PATH=databases/SQLite.db

WEB_HOST=0.0.0.0
WEB_PORT=8000

LOG_LEVEL=INFO
LOG_FILE=logs/app.log
```
### 3 Запуск backend

```
python main.py
Backend API и временный UI будут доступны на http://localhost:8000
```
Планировщик и бот запускаются автоматически

## Авторизация через OAuth (VK ID)

В проект встроен базовый OAuth-flоw для входа через VK ID, который защищает временный web UI.  
Чтобы включить авторизацию:

1. Зарегистрируйте приложение VK ID и получите `VK_CLIENT_ID` и `VK_CLIENT_SECRET`.
2. Укажите redirect URL в настройках VK:  
   `http://localhost:8000/auth/vk/callback` (или ваш публичный адрес).
3. Укажите список разрешённых VK ID в `ALLOWED_VK_IDS` (через запятую).
4. Заполните переменные в `.env` и включите флаг `AUTH_ENABLED=true`.

После этого доступ к странице рассылок будет только у авторизованных пользователей.

### Где взять FLASK_SECRET_KEY и VK ID ключи

- **FLASK_SECRET_KEY** — любая длинная случайная строка (используется для подписи сессий).  
  Пример генерации: `python -c "import secrets; print(secrets.token_urlsafe(32))"`.
- **VK_CLIENT_ID** и **VK_CLIENT_SECRET** выдаются в кабинете VK ID:
  1) зайдите в **VK ID** → **Мои приложения**;
  2) создайте приложение (тип веб/сайт);
  3) в карточке приложения возьмите `Client ID` и `Client Secret`;
  4) добавьте redirect URL, совпадающий с `VK_REDIRECT_URI`.
