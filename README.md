# VK_bot - back-end

Backend-часть командного проекта для **отложенных рассылок сообщений** в VK Teams.

 **Проект находится в активной разработке.**  
Данный ветка представляет только back-end часть и **не является финальной версией продукта**.

---

## О проекте

Проект разрабатывается командой и в будущем будет включать:

-  **Полноценный web-сайт** (отдельный frontend)
-  **Авторизацию и роли пользователей**
-  Расширенную аналитику рассылок
-  Масштабируемую архитектуру

> Текущий web-интерфейс в этом репозитории — **временный технический UI**,  
> используется **исключительно для отладки и демонстрации backend-логики**  
> и **будет заменён** полноценным frontend-приложением.


---

## Назначение этой ветки

Эта ветка сфокусирована на backend-задачах:

- обработка и хранение рассылок
- планирование отправки
- доставка сообщений через бота
- идемпотентность (без дублей)
- API для будущего frontend
- логирование и конфигурация

---

## Реализовано на данный момент

-  Отправка сообщений `now` или по времени (UTC)
-  Повторные попытки отправки без дублей
-  Хранение данных в SQLite (временное решение)
-  Интеграция с VK Teams Bot API
-  Временный Flask UI
-  API для получения статистики
-  Конфигурация через `.env`
-  Централизованное логирование

## Запуск (для разработки)

### 1 Установка зависимостей
```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
### 2️ Конфигурация
```
cp .env.example .env
```
Пример .env:
```
BOT_TOKEN=your_vk_teams_bot_token
DB_PATH=databases/SQLite.db

WEB_HOST=0.0.0.0
WEB_PORT=8000

LOG_LEVEL=INFO
LOG_FILE=logs/app.log
```
### 3 Запуск backend

```
python main.py
Backend API и временный UI будут доступны на http://localhost:8000
```
Планировщик и бот запускаются автоматически

##  API (backend)
Пример:

```
GET /api/stats/<message_id>
```

Ответ:

```
{
  "id": 1,
  "message": "Hello!",
  "message_time": "2025-11-25 15:30",
  "sent": 2,
  "clicks": 0
}
```
API будет расширяться и использоваться frontend-приложением.
